# Analytical Experiments

This directory preserves selected exploratory and model-comparison work completed during development of the merchant analytics pipeline.

## Sentiment experiments

The sentiment experiments document the progression from exploratory analysis and text preprocessing through feature extraction, TF-IDF/logistic regression, DistilBERT sentiment analysis, model comparison, and sentiment consolidation.

The `src` directory contains helper modules used by these historical experiments.

## Customer-theme experiment

The customer-theme analysis represents an additional analytical approach explored during development.

These files are retained to document analytical iteration and model-selection decisions. They are not part of the supported production pipeline. The finalized pipeline is maintained in the main `scripts/` and `src/` directories.
